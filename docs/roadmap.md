# Roadmap

Reference unit: **96 MXS**. Quarters are fiscal years (FY27 Q1 = Oct–Dec 2026). Dates are targets, gated on AI Factory selection and accreditation timelines.

| Phase | When | Build | Exit gate |
|---|---|---|---|
| 0. Pitch & prototype | FY27 Q1 | Clickable demo on synthetic 96 MXS data; one-pager and deck; AI Factory submission | Selected / sponsor identified |
| 1. MVP | FY27 Q2 | Journal, SEL setup interview, award rules + six-line check, routing member → SEL, AI coach + editor; dev environment, synthetic data | Full cycle runs end-to-end on synthetic data |
| 2. 96 MXS pilot | FY27 Q3 | IL4 environment on the AI Factory platform; PIA and privacy review; inherited-control ATO path; one real quarterly cycle; AI scorer + reviewer copilot | Pilot metrics met; authority to operate for pilot |
| 3. Group & wing | FY27 Q4 – FY28 Q1 | Layered nominations (squadron → 96 MXG → wing), group/wing templates, anonymized board scoring, suspense dashboards, evaluation drafts | Second squadron onboarded in < 1 day |
| 4. Enterprise | FY28+ | Other wings; both AWS GovCloud and Azure Government; IL5 option; export/integration with official systems | Enterprise sponsor and sustainment funding |

## Pilot metrics
- Hours saved per package (member + supervisor)
- Review rounds per package and turnaround per step
- % of packages on time at each suspense
- % rule-compliant on first submission
- Journal entries per member per month
