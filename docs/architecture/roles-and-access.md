# Roles & Access

| Role | Scope | Can |
|---|---|---|
| Member | Self | Journal, draft packages, chat with coach, see own package status |
| First Supervisor | Direct reports | Review, comment, suggest edits, AI score, return/forward |
| Flight Leadership (Flight CC / Flight Chief) | Flight | Coordinate, return/forward, see flight dashboard and suspense status |
| SEL | Squadron | **Configure award programs, eligibility, rules, routing and cycle dates**; approve nominations |
| Commander | Squadron | Read dashboards, final approval if the routing template requires it |
| Board Member | Assigned cycle | Score anonymized packages only |
| Wing/Group Admin | Wing/Group | Maintain templates that units inherit |

Access is computed from **org membership + role + effective dates** (ABAC). Supervisors never see a subordinate's private journal, only what is placed into a submitted package.
